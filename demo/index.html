img2threejs

Görsel → renkli 3D model (GLB). Tarayıcıda, sunucusuz, kotasız, ücretsiz. İlk üretimde ~26 MB AI modeli iner, sonra önbellekten çalışır.
🖼️ Görseli buraya bırak veya tıkla
Sade arka planlı tek nesne en iyi sonucu verir
Hazır — bir görsel seçin.
📚 Kütüphane kullanımı 
import { imageToGLB, setProgressLogger } from "./src/index.js";
// veya CDN (repo Pages'ten):
// import { imageToGLB } from "https://bilfen.github.io/img2threejs/src/index.js";

setProgressLogger(console.log);
const glb = await imageToGLB(fileOrUrl);   // → Blob "model/gltf-binary"
// indir: URL.createObjectURL(glb)
